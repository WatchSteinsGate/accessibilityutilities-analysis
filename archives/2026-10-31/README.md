## Integrity

All eleven asset sizes and GitHub-reported SHA-256 digests match the supplied files. [SHA256SUMS](SHA256SUMS) verifies downloaded originals; the [publication manifest](../../results/source-attachments/2026-10-31-original-files.json) records each asset ID, direct download link, size and SHA-256.

From a directory containing all eleven downloaded originals, run `sha256sum -c /path/to/this/SHA256SUMS`. From the repository root, `python tools/validate-original-attachments.py` validates the retained publication metadata; add `--directory /path/to/downloaded-originals` to verify actual local bytes. None of these checks execute archive members.

## Storage and scope

The user clarified that the ZIP files themselves, not substitute summaries, were the requested deliverable.
